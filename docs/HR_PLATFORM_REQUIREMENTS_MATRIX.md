## 1. Status Definition Standard
- **PASS**: Verified through direct execution, deterministic calculation tests, or end-to-end browser workflows.
- **PARTIAL**: Substantial implementation exists, but edge conditions or full spec completeness are not fully met.
- **FAIL**: A requirement is missing, broken, insecure, or demonstrably incorrect.
- **BLOCKED**: Verification cannot proceed due to missing external credentials, third-party services, or environment access.
- **NOT APPLICABLE**: Requirement genuinely does not apply to this system scope (with documented justification).
